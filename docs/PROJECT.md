# KUMA CHESS WORLD

## 제품 비전

KUMA CHESS WORLD는 체스를 중심으로 퍼즐, AI, 마주보기 대전과 짧은 보드 미니게임이 연결되는 동물 왕국 게임 모음이다. 각 게임은 같은 캐릭터, 기물, 코인, 메달, 음악, UI 문법을 공유한다.

## 사용자

- 체스를 처음 배우는 어린이와 가족
- 짧은 전술 퍼즐을 반복해서 즐기는 사용자
- 한 기기를 사이에 두고 함께 플레이하려는 친구·부모·아이
- 동물 기물과 수집 요소에 매력을 느끼는 캐주얼 사용자

## 핵심 경험

1. **배운다**: 용어 설명, 힌트, 단계별 퍼즐로 규칙과 전술을 익힌다.
2. **마주한다**: 로컬 PvP에서 상대와 화면을 공유하고 대화한다.
3. **수집한다**: 플레이로 코인, 기물, 메달을 얻는다.
4. **돌아온다**: 데일리 미션과 짧은 게임으로 매일 할 일을 제공한다.
5. **확장한다**: 익숙한 기물을 다른 규칙의 미니게임에서도 사용한다.

## 현재 애플리케이션 구조

- `src/scenes/Start.js`: 메인 허브
- `src/scenes/PuzzleSelect.js`, `Puzzle.js`: 퍼즐 선택과 플레이
- `src/scenes/PieceSelectAI.js`, `Game.js`: AI 설정과 대국
- `src/scenes/PieceSelect.js`, `Game.js`: 마주보기 대국
- `src/scenes/Result.js`: 결과와 보상
- `src/scenes/MedalCatalog.js`: 메달 도감
- `src/dailyMissions.js`, `src/ui/DailyMissionPopup.js`: 데일리 미션
- `src/playerState.js`: 코인, 설정, 수집, 통계의 로컬 상태
- `src/medals.js`: 메달 정의와 조건 추적
- `src/puzzles.js`: 검증된 100개 퍼즐

## KUMA CHESS WORLD 허브 구상

첫 화면에서 KUMA CHESS를 가장 큰 대표 타일로 유지한다. 그 아래에 미니게임을 작은 타일로 배치한다. 기존의 퍼즐·AI·마주보기 진입은 체스 타일 안에서 유지하거나 대표 바로가기로 남긴다.

데스크톱의 넓은 좌우 여백은 콘텐츠를 침범하지 않는 광고 영역으로 사용할 수 있다. 모바일에서는 해당 광고 영역을 숨기고 게임과 문서 콘텐츠를 우선한다. 개인정보처리방침, 게임 소개, 이용 방법은 게임 아래의 읽을 수 있는 HTML 콘텐츠로 제공하고 메뉴 링크는 해당 섹션으로 스크롤한다.

## 데이터와 서비스 경계

현재 상태는 브라우저 `localStorage`에 저장한다. 따라서 사용자가 자신의 코인과 진행도를 수정하는 것을 보안으로 막을 수 없다. 서버 검증이 필요한 온라인 대전, 계정 동기화, 쿠폰, 결제, 강한 부정행위 방지는 별도 백엔드 단계로 취급한다.

## 성공 기준

- 처음 방문한 사용자가 30초 안에 퍼즐이나 대국을 시작한다.
- 사용자가 퍼즐, AI, 미션, 수집 중 다음 행동을 쉽게 발견한다.
- 모바일 세로 화면에서 UI 겹침과 잘림이 없다.
- 게임 진행 중 사운드·진동·메시지가 행동 결과를 명확하게 전달한다.
- 신규 미니게임이 기존 아트와 경제를 재사용하면서도 체스의 정체성을 흐리지 않는다.
