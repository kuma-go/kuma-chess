# 결정 기록

## 2026-07-30: 프로젝트를 KUMA CHESS WORLD로 관리

- 체스를 대표 게임으로 유지한다.
- 같은 IP, 기물, 코인, 메달, UI를 사용하는 미니게임을 단계적으로 추가한다.
- 배포 코드 저장소와 원본 디자인 폴더를 Codex 로컬 프로젝트의 주·보조 폴더로 관리한다.
- 서로 다른 결과물은 별도 작업으로 나누고, 지속 규칙은 저장소 문서에 기록한다.

## 2026-07-30: 첫 미니게임 후보는 왕국 알까기

- 기존 체스보드와 기물 리소스를 재사용한다.
- 자기 쪽 3개 랭크에 기물을 자유 배치한다.
- 새총처럼 드래그해 발사하고 기물마다 질량 차이를 둔다.
- 상대 왕을 보드 밖으로 밀어내면 승리한다.
- 구현 전 별도 프로토타입에서 조작감과 밸런스를 검증한다.

## 2026-07-30: 웹 허브와 문서 콘텐츠 통합

- 메인 게임 아래에 소개, 방법, 음악, AI 활용, 연락처 콘텐츠를 읽을 수 있는 HTML로 제공한다.
- 기존 문서 버튼은 별도 빈 페이지보다 해당 섹션으로 스크롤하는 용도로 전환한다.
- 데스크톱 좌우 광고는 게임 조작과 분리하고 모바일에서는 숨길 수 있다.

## 2026-07-30: 공유 경제

- KUMA CHESS WORLD의 게임들은 하나의 코인 지갑을 공유한다.
- 미니게임 반복 파밍에는 일일 완화나 상한을 둔다.
- 구매와 수집은 외형·진행 목표이며 PvP 성능을 높이지 않는다.

## 2026-07-31: 로컬 저장 안정화와 프로필 분리

- 코인, 기물, 데일리 미션, 퍼즐, 메달 저장값은 기본 키와 백업 키에 함께 기록한다.
- 기본 키가 비어 있거나 JSON 파싱에 실패하면 백업 키에서 복구하고 기본 키를 다시 수리한다.
- 언어, 사운드, BGM, 진동, 표시 이름, 아바타는 `kumaChessProfileState`로 분리한다.
- 기존 `kumaChessPlayerState`에 있던 프로필 필드는 첫 실행 시 새 프로필 저장소로 마이그레이션한다.

## 2026-07-31: 황금 곰·브라운 베어 런타임 연결

- 원본 폴더의 황금 곰·브라운 베어 기물 앞/뒤 이미지를 런타임 에셋으로 연결한다.
- 두 특수 세트는 흰색·검은색 양쪽 진영에서 선택할 수 있다.
- 기본 18개 기물 색상 수집률과 보물 수집가 메달 조건에는 포함하지 않는다.
- 황금 곰은 세트 직접 구매가 아니라 Pawn, Knight, Rook, Bishop, Queen, King 황금 기물 6종을 모두 모으면 백/흑 세트가 함께 해금된다.
- 브라운 베어는 선택 화면에서 획득 조건을 직접 설명하지 않는 숨겨진 보상으로 둔다.
- 현 단계 숨겨진 보상과 광고 보상은 로컬 진행 플래그이며, 공개 웹 클라이언트에 비밀 검증 키를 넣지 않는다.

## 기존 핵심 결정

- KUMA CHESS는 가족이 마주 앉아 즐기는 온기를 우선한다.
- 흰색·검은색 동물 기물은 별도로 수집한다.
- 마주보기 PvP는 보드를 교환하지 않고 기물과 UI 방향을 전환한다.
- 퍼즐은 색상만 바꾼 반복 대신 서로 다른 전술을 제공한다.
- 힌트는 퍼즐 보상보다 낮은 코인 비용을 사용한다.
- 메달과 데일리 미션은 장기 목표를 제공한다.
- 공개 웹 클라이언트에는 비밀 키를 넣지 않는다.
