# 디자인 시스템

## 화면 기준

- 게임 논리 해상도: `720 x 1280`
- 세로 화면 우선, 넓은 화면에서는 가운데 게임과 양쪽 월드 배경을 유지
- iOS의 `safe-area-inset-*`, 동적 뷰포트, 홈 화면 실행을 고려
- 회전 후에도 콘텐츠가 잘리거나 캔버스 비율이 깨지지 않아야 한다

## 폰트

- 대형 메인/START 버튼: `Noto Serif KR`, Bold, `#342B1F`
- 일반 버튼: `Pretendard`, Bold
- 작은 설명과 보유 재화: `Pretendard`, Medium
- 메달 이름: `Pretendard`
- 긴 영문·일문은 두 줄을 허용하고 다른 열을 침범하지 않게 한다
- 글자 간격은 `0`; 뷰포트 너비에 따라 글꼴 크기를 무한 확대하지 않는다

## 색과 배경

- 외부 여백 기본색: `#EDDEC1`
- 하단 `pattern_bottom_bg`는 가로에 맞춰 고정
- `pattern`은 약 `-6deg` 회전해 반복하고 매우 천천히 이동
- 본문은 아이보리, 금색, 갈색, 청록 상태색, 붉은 실패색을 함께 사용해 단색 팔레트가 되지 않게 한다

## 체스보드와 기물

- 보드 칸과 상호작용 영역은 정확히 같은 크기
- 기물 기준점은 칸의 하단 중앙
- 선택 표시는 기물 아래 레이어에 놓고 칸과 정확히 일치
- 이동 가능 표시, 마지막 수, 힌트 표시는 기물보다 아래
- 퍼즐, AI, PvP가 같은 배치 보정 값을 공유
- 처치 기물은 종류별로 읽을 수 있는 크기로 정렬

## 마주보기 모드

- 흑 차례에도 진영의 좌표 자체를 바꾸지 않는다
- 기물은 제자리에서 상대 플레이어를 향하는 앞/뒤 리소스로 전환
- 흑 차례 안내, 흑 측 처치 목록, 흑 승급 팝업은 흑 플레이어 방향으로 반전
- 흑 처치 목록은 오른쪽 위에서 오른쪽부터 정렬
- 턴 전환 모션은 기물이 사라지는 구간 없이 기존/교체 리소스가 겹쳐 이어진다

## 팝업

- 배경은 딤드와 약한 블러를 함께 사용
- 구매 팝업의 보유 코인은 딤드보다 위에 둔다
- 내용이 길면 중앙 패널을 늘리거나 내부 스크롤을 제공
- 확인 버튼이 없어도 되는 정보 팝업은 바깥/전체 터치로 닫는다
- 닫기 동작과 구매·적용처럼 의미가 다른 동작을 혼동하지 않는다

## 상태와 연출

- 성공: 청록 라인 메시지, 사운드, 필요한 경우 진동과 파티클
- 실패: 붉은 라인 메시지와 분명한 피드백
- 보상/메달: 메시지 → 긴장감 있는 파티클 → 보상 공개 순서
- 메달 획득 화면은 사용자가 탭할 때까지 유지
- 새 콘텐츠의 `N` 배지는 실제 확인 후 사라짐
- 미수령 보상이 있으면 해당 버튼에 절제된 반짝임
- `prefers-reduced-motion`에서는 장식 모션을 줄인다

## UI 검수 체크

- 390x844, 430x932, 720x1280, 넓은 데스크톱
- 한국어/영어/일본어
- 브라우저와 홈 화면 설치 실행
- 노치·홈 인디케이터·주소창 변화
- 팝업, 구매 코인, 스크롤, 키보드 포커스
- 보드 초기 배치, 중반 기물, 승급, 체크메이트, 처치 목록
