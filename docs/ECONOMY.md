# 코인과 보상 경제

## 원칙

- 코인은 KUMA CHESS WORLD 전체가 공유하는 재화다.
- 플레이 보상은 수집을 돕지만 한두 번의 플레이로 전체 상점을 끝내지 못하게 한다.
- PvP에서는 외형과 수집만 공유하고 성능 차이는 만들지 않는다.
- 로컬 저장 데이터는 사용자가 수정할 수 있으므로 경쟁 순위나 현금 가치가 있는 재화로 취급하지 않는다.

## 기물 수집

- 흰색과 검은색 세트는 별도 구매·해금
- 초반에는 낮은 가격의 선택지를 두어 첫 구매 경험을 빠르게 제공
- 일부 세트는 코인 대신 퍼즐·AI·데일리 미션 조건으로 획득
- 모든 기물을 산 뒤에도 메달, 데일리, 특수 세트, 향후 카드를 목표로 남긴다

## 황금 곰·브라운 베어

- 황금 곰과 브라운 베어는 기본 18개 수집률에 포함하지 않는 특수 기물 세트다.
- 황금 곰은 색상별 직접 구매가 아니라 6개 황금 기물을 모두 모으면 백/흑 세트가 함께 해금된다.
- 현재 황금 기물 조건은 Pawn 500코인, Knight 600코인, Rook 데일리 완료 100일, Bishop 700코인, Queen 광고 보상, King 1000코인이다.
- 브라운 베어는 선택 화면에서 획득 조건을 직접 설명하지 않는 숨겨진 보상 세트다.
- 설정 화면의 일반 쿠폰 입력은 향후 여러 숨겨진 보상을 처리하는 공용 입구로 둔다.
- 두 세트 모두 PvP 성능을 높이지 않는 외형 수집 요소다.

## 미니게임 보상 가이드

- 짧은 1판: 1~3코인
- 승리: 난이도와 평균 플레이 시간에 따라 3~8코인
- 같은 게임 반복 보상은 일일 완화 또는 횟수 제한 적용
- 데일리 미션이 다양한 모드를 순환하도록 해 한 게임만 반복 파밍하지 않게 한다
- 출시 전 시간당 예상 코인을 계산하고 기존 AI 어려움 보상과 비교한다

## 카드 시스템 후보

결과 전용 일러스트를 카드로 전환하는 아이디어는 후보 단계다.

- 해당 동물 기물로 50~100회 플레이하면 카드 획득
- 보유 효과는 해당 기물로 AI 승리 시 소폭 추가 코인
- 코인으로 요구 플레이 횟수를 일부 단축할 수 있음
- PvP 성능에는 영향을 주지 않음
- 효과 중첩 상한과 회수 기간을 먼저 설계한 뒤 구현
