# KUMA CHESS 프로젝트 컨텍스트

새 작업을 시작할 때 가장 먼저 읽는 요약 문서다.

## 한 문장 정의

KUMA CHESS는 왕관을 쓴 동물 기물로 체스를 배우고, 퍼즐과 AI 대전, 한 기기를 사이에 둔 마주보기 대전을 즐기는 세로형 웹/PWA 게임이다.

## 제작 의도

초등학생 아들을 위해 시작한 체스 게임이다. 혼자 스마트폰만 바라보는 경험보다 마주 앉아 체스를 두고 대화하는 온기를 담는 것이 핵심이다. 디자인, 일러스트, 음악은 KUMA CHESS를 위해 제작되었고 생성형 AI를 제작 보조 도구로 활용했다.

## 현재 구현

- 원본 `ui/main_update` 시안의 중앙 `1080 x 26640` 좌표와 순서를 내부 재배치 없이 축소하고, 텍스트는 실제 HTML로, 삽화는 개별 이미지로 구성한 유일한 웹 메인과 콘텐츠 전용 `play.html` 런타임. 게임 iframe은 한 번 예열해 재사용하고 모든 홈 복귀는 웹 메인으로 통합한다. 표시 폭은 기존 720 x 1280 게임과 동일하게 `min(100vw, 56.25dvh, 720px)`로 맞춘다. 데일리 미션·설정·게임 정보·메달 도감은 투명 임베드 캔버스에서 기존 Phaser UI를 재사용하고 부모 웹 메인을 블러 처리한다. 설정 적용 뒤 웹 메인의 조작 문구와 하단 전체 설명도 공유 프로필의 `ko/en/ja` 언어를 즉시 따른다. 메달 획득 조건과 진행률은 목록이 아니라 기존 카드 상세 팝업에서 확인한다. 콘텐츠 게임 오버레이의 캔버스 밖 영역은 불투명 패턴으로 채워 모바일 세로 여백에 웹 메인이 비치지 않게 한다.
- Phaser 3 기반 `720 x 1280` 세로 게임
- 퍼즐 100개(다단계 65개), 순차 해금, 힌트 코인 비용
- 쉬움/보통/어려움/도전 AI와 난이도별 보상. 도전은 일반 체스 전용이며 별도 웹 워커의 반복 심화 알파베타 탐색을 사용한다.
- 한 기기에서 마주보고 하는 로컬 PvP
- Firebase 익명 UID와 6자리 초대 코드를 사용하는 비랭크 온라인 1:1 체스. 웹 메인의 기존 양피지 팝업에서 방 생성·코드 참가·대기를 처리하고, 연결된 뒤 실시간 수 동기화·진행 방 복구·기권을 지원한다. 서버 합법 수 검증 전에는 코인·메달·순위 보상을 지급하지 않는다.
- 흰색/검은색 동물 기물의 개별 구매·해금·선택
- 공용 코인, 접속/퍼즐/AI/설치/미션 보상
- 메달 81개와 신규 획득 표시. 체스·퍼즐뿐 아니라 5종 미니게임, 포탈·아이템, BGM 감상, 메인 설명 완독 기록도 중복 방지 이벤트 ID로 누적한다. 자체 도전 AI 승리 메달과 향후 Stockfish 18 Lite용 준비 항목은 기존 온라인 도전장과 별도 항목이다.
- 날짜별 데일리 미션과 연속·누적 완료 기록. 체스뿐 아니라 5종 미니게임의 플레이·승리·종목 다양성도 일일 후보에 포함한다.
- 황금 곰·브라운 베어 특수 기물 세트. 흑 브라운 곰은 전용 6종 앞·뒤 리소스를 사용하고 텍스처 키와 파일 URL을 함께 버전 처리하며, 조건 해금은 실제 기물 이미지가 포함된 순차 라인 알림으로 표시한다.
- 한국어/영어/일본어, 효과음, BGM, 진동
- PWA 설치, 화면 켜짐 유지, 모바일 안전 영역 대응
- 로컬 브라우저 저장과 GitHub Pages 배포. Firebase 익명 인증으로 프로필 설정과 검증 전 진행 요약을 소유자 전용 Firestore 문서에 백업하며, 서버가 작성한 주간·전체 체스 순위 문서는 읽기 전용으로 표시한다. 코인·보상과 공식 순위 점수는 아직 서버 권한 데이터로 이전되지 않았다.
- 광고 촬영용 자동 대국 데모
- 기존 기물·UI를 재사용한 왕국 힘겨루기와 왕국의 길 플레이 가능 프로토타입
- 왕관 쟁탈전의 규칙 엔진·플레이 장면·AI/마주보기 모드·기물 선택·결과 화면과 전용 주사위 연출
- 왕국 공성전의 AI/로컬 마주보기 규칙 엔진·실시간 기물 배치·자동 전투·상자·포탈·결과 화면
- 메인 화면에서 독립 진입하는 왕국의 길 싱글 퍼즐 24스테이지(길 연결·미로 탐험·혼합형), 왕관 평가와 독립 진행 저장
- 미니게임 진입 전 `790 x 990` 세로 패널 안에서 80% 일러스트 카드와 원형 모드 아이콘으로 AI/마주보기 플레이를 선택하는 공통 팝업

현재 온라인 PvP는 초대 코드 기반 비랭크 단계이며 매치메이킹, 제한시간, 서버 합법 수 판정은 아직 없다. 등록형 서버 계정, 서버 검증 경제, 네이티브 앱도 없다. Firebase 익명 UID는 클라우드 동기화 기반일 뿐 다른 기기에서 복구 가능한 정식 계정이 아니다. 도전 AI를 포함한 AI는 Stockfish가 아닌 프로젝트 자체 브라우저 엔진이다. 도전 AI는 기존 어려움보다 깊게 탐색하지만 세계 최강을 보증하지 않는다. AdSense 소유권 확인 스크립트와 웹 메인의 좌우·본문 광고 슬롯 구조는 있으나 실제 슬롯 ID와 노출은 아직 비활성 상태다.

## 다음 확장 방향

KUMA CHESS를 하나의 월드로 확장한다. 메인 체스가 대표 게임이고 같은 기물·코인·메달·UI를 공유하는 짧은 미니게임을 추가한다.

1. 왕국 힘겨루기와 왕국의 길 안정화
2. 왕관 쟁탈전 모바일 조작·AI 밸런스 안정화
3. 왕국 공성전 AI 난이도·멀티터치·전투 템포 밸런스 안정화
4. 황금 곰·브라운 베어 특수 기물 세트
5. 수집 카드와 보유 효과
6. 프로필·플레이 기록·코인 원장을 검증하는 서버 계정과 리더보드
7. 초대 코드 온라인 1:1의 서버 합법 수 검증·시간 제한·운영 안정화 및 도전 AI 승리 전체 알림

계획 항목은 구현된 기능처럼 표시하지 않는다.
